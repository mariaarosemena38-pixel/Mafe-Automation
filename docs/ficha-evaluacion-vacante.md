# Ficha de evaluación de vacantes

Cada vacante que llegue a la cola se revisa con esta ficha. Una estimación de éxito no es una promesa de contratación: indica qué tan bien encaja el CV publicado con los requisitos visibles y qué tan probable es superar una primera revisión.

## Información de la vacante

| Campo | Pregunta |
| --- | --- |
| Puesto y empresa | ¿Cuál es el cargo y quién contrata? |
| Vigencia | ¿Cuándo se publicó y sigue disponible? |
| Fuente | ¿Cuál es el enlace directo u original? |
| Oficina y traslado | ¿Dónde queda la oficina o qué zona se publica? ¿Qué ruta, tiempo y costo estimado implicaría? |
| Modalidad | ¿Remoto, híbrido o presencial? ¿Cuántos días en casa? |
| Jornada | ¿Tiempo completo, horario exacto, zona horaria y trabajo en sábado? |
| Compensación | ¿Salario, bono, comisiones, seguro, vacaciones, formación, equipo, viáticos u otros beneficios? |

## Compatibilidad con el CV

| Campo | Pregunta |
| --- | --- |
| Compatibilidad | ¿Alta, media o baja y por qué? |
| Habilidades demostrables | ¿Qué exige el puesto que ya está respaldado en el CV? |
| Brechas | ¿Qué requisito falta, requiere evidencia adicional o aprendizaje? |
| Riesgos de descarte | ¿Nivel de inglés, años de experiencia, título, seniority, software o sector? |
| Probabilidad estimada | ¿Qué porcentaje razonable hay de superar la preselección, acompañado de supuestos claros? |
| Adaptación | ¿Qué logro, palabra clave o versión del CV conviene priorizar? |

## Decisión

La ficha termina con una de estas acciones: `revisar hoy`, `preparar CV`, `guardar como opción`, `pedir información` o `descartar`. No pasa a `enviar` sin aprobación humana explícita.

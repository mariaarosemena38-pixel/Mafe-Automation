## Estados permitidos

`descubierta` → `evaluada` → `pendiente de revisión` → `borrador listo` → `aprobada` → `enviada` → `seguimiento` → `entrevista` o `cerrada`.

Para cada entrada se debe conservar el enlace original, la fecha publicada si aparece, la fecha de hallazgo y el motivo de cualquier descarte. Nunca registrar contraseñas, códigos de acceso, teléfono, correo personal, CVs ni otros datos sensibles en este repositorio público.
